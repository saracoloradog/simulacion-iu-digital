INTRODUCCIÓN

En esta actividad trabajé con el juego de Yahtzee para entender mejor cómo funciona una simulación cuando hay resultados que no podemos predecir con exactitud. El juego utiliza cinco dados, y cada lanzamiento puede terminar en una combinación distinta. Justamente por eso me pareció una buena forma de comenzar a practicar conceptos de probabilidad.

Primero organicé las reglas del juego y las categorías de puntuación para construir una versión en Python de dos jugadores. La idea fue que cada jugador pudiera lanzar los dados hasta tres veces por turno, decidir cuáles conservar y registrar su puntuación sin repetir categorías.

Después preparé un experimento con el método de Montecarlo. En lugar de jugar una sola partida, el programa repite 100.000 veces el lanzamiento de cinco dados para observar qué tan seguido aparece cada cara y cuántas veces se consigue una combinación de cinco números iguales.

También preparé una demostración visual en el navegador. Así puedo mostrar cómo funcionan los turnos y las decisiones de los jugadores, mientras el código en Python permite revisar el algoritmo y reproducir el experimento estadístico.

Más que buscar un resultado específico, el ejercicio consiste en comparar lo que esperamos según la probabilidad con lo que realmente ocurre en una simulación y explicar por qué los resultados no son idénticos en todos los intentos.

OBJETIVOS Y DESCRIPCIÓN DEL PROBLEMA

Objetivo general

Desarrollar una simulación del juego Yahtzee para dos jugadores y utilizar el método de Montecarlo para analizar los resultados de lanzamientos aleatorios de cinco dados.

Objetivos específicos

  • Representar cinco dados de seis caras con la misma probabilidad de obtener cada número.
  • Implementar turnos con hasta tres lanzamientos y la opción de conservar dados.
  • Calcular y guardar la puntuación de las 13 categorías del juego.
  • Repetir lanzamientos mediante Montecarlo para comparar resultados experimentales con probabilidades teóricas.
  • Presentar el procedimiento y los resultados de una forma que se pueda revisar y probar.

¿Qué se está simulando?

Cada dado puede tomar uno de seis valores: 1, 2, 3, 4, 5 o 6. Como trabajamos con dados equilibrados, todos tienen la misma probabilidad de salir. Los lanzamientos son independientes: el valor de un dado no depende del resultado anterior.

P(X = x) = 1/6   para x ∈ {1, 2, 3, 4, 5, 6}
Dos partes del proyecto

🎲 Juego: dos participantes toman decisiones, conservan dados y anotan puntos.

📊 Experimento: el programa repite lanzamientos independientes y registra frecuencias.

No son exactamente el mismo procedimiento: en una partida intervienen las decisiones; en el experimento se estudia el azar sin estrategia.

METODOLOGÍA

1. Definir las reglas

El juego se organiza en 13 rondas por jugador. En cada ronda se lanzan cinco dados y se permiten hasta tres lanzamientos. El jugador puede conservar algunos resultados para tratar de mejorar su combinación. Al final debe seleccionar una categoría que todavía no haya utilizado.

2. Representar los dados y la puntuación

En Python utilicé una lista para guardar los cinco valores y un diccionario para registrar las categorías de cada participante. Así es posible consultar qué categorías están disponibles y calcular el resultado acumulado.

3. Implementar el lanzamiento

Para los dados utilicé un generador pseudoaleatorio de Python. Cada cara se obtiene con la misma posibilidad. Cuando un dado está marcado para conservarse, no se modifica en el siguiente lanzamiento.

4. Ejecutar Montecarlo

Después de implementar el juego, repetí 100.000 lanzamientos independientes de cinco dados. En cada iteración registré los números obtenidos y revisé si los cinco dados eran iguales. Utilicé la semilla 2026 para poder repetir el experimento y comparar los mismos resultados.

Secuencia de la simulación

INICIO → GENERAR 5 DADOS → REGISTRAR RESULTADOS → ¿SON IGUALES? → REPETIR N VECES → ANALIZAR

5. Validar los resultados

Comprobé casos conocidos de puntuación, como full, escaleras y Yahtzee, además de verificar que los dados se generen entre 1 y 6. El repositorio incluye las pruebas para poder repetir estas comprobaciones.

IMPLEMENTACIÓN DE LA SOLUCIÓN

La implementación principal está desarrollada en Python y se puede ejecutar desde la terminal. Incluye dos modos: uno para jugar una partida y otro para repetir lanzamientos con Montecarlo.

Componentes principales
FunciónQué hace
lanzar_dados()Genera cinco valores del 1 al 6 y permite conservar posiciones.
puntuar()Calcula los puntos según la categoría elegida.
jugar()Controla las rondas y los turnos de los dos jugadores.

Cómo ejecutar el proyecto

python modulo-1/yahtzee/yahtzee_montecarlo.py --jugar

python modulo-1/yahtzee/yahtzee_montecarlo.py --simulaciones 100000 --semilla 2026

Ejecuta el experimento con una semilla fija.

ANÁLISIS DE LOS RESULTADOS

Probabilidad de obtener Yahtzee

Para obtener un Yahtzee en un solo lanzamiento, los cinco dados deben mostrar el mismo número. No importa si son unos, doses o seises: cualquiera de las seis combinaciones sirve.

P(Yahtzee) = 6 × (1/6)⁵ = 1/1296 ≈ 0,07716 %

En 100.000 lanzamientos, el valor esperado es de aproximadamente 77 casos. El programa registró 79, una cantidad muy cercana, aunque no exactamente igual.

¿Por qué no coinciden exactamente?

Porque cada lanzamiento tiene un resultado aleatorio. Cuando repetimos el experimento muchas veces, las proporciones suelen acercarse a los valores teóricos, pero eso no significa que todas las frecuencias tengan que coincidir de manera perfecta. Esa fue una de las ideas más importantes que pude comprobar con este ejercicio.

Importante: este cálculo corresponde a obtener cinco dados iguales en un lanzamiento. Una partida real permite conservar dados y volver a lanzar, así que la probabilidad de lograr un Yahtzee durante un turno depende también de las decisiones del jugador.

CONCLUSIONES

Con esta actividad entendí que simular no es solamente generar números al azar. Primero hay que pensar cómo funciona el sistema que queremos representar, definir sus reglas y comprobar que el programa las esté cumpliendo.

El juego de Yahtzee me permitió trabajar con decisiones de los jugadores, categorías de puntuación y lanzamientos que no siempre terminan como esperamos. Además, al repetir el experimento de Montecarlo pude ver la diferencia entre conocer una probabilidad en teoría y observarla en la práctica.

Me llamó la atención que, incluso con 100.000 intentos, no se obtienen proporciones perfectas. Aun así, los resultados se acercaron bastante a los valores esperados. En particular, los 79 Yahtzees observados son muy próximos a los 77 que se esperarían aproximadamente.

También fue útil separar el juego interactivo del experimento estadístico: el primero sirve para comprender las reglas y probar distintas decisiones; el segundo permite analizar el comportamiento de los dados cuando se repite una misma situación muchas veces.

Me queda más claro para qué sirve el método de Montecarlo y por qué es importante verificar el código y explicar las condiciones del experimento antes de sacar conclusiones.
