¿Qué pasa si lanzamos cinco dados miles de veces?

En este laboratorio puedo repetir el mismo experimento tantas veces como quiera. Cada intento consiste en lanzar cinco dados equilibrados y comprobar qué caras salieron y si todos quedaron iguales. La idea es comparar los resultados de la simulación con las probabilidades que conocemos por teoría.

Selecciona una cantidad y ejecuta el experimento. Cada ejecución genera resultados nuevos.

Con pocas repeticiones es normal que los resultados sean bastante diferentes del valor teórico. Aumentar la cantidad de intentos ayuda a observar la tendencia, aunque no garantiza una coincidencia exacta.

¿QUÉ ESTOY SIMULANDO EXACTAMENTE?

Un intento son cinco dados lanzados una sola vez. Los dados se generan de forma independiente, con las seis caras igualmente probables. Un Yahtzee aparece cuando los cinco muestran el mismo valor.

Probabilidad teórica: P(Yahtzee) = 6 × (1/6)⁵ = 1/1296 ≈ 0,07716 %.

Esto es distinto de una partida de Yahtzee: en el juego sí podemos conservar dados, hacer hasta tres lanzamientos por turno y tomar decisiones. Aquí aislamos el azar para analizarlo con Montecarlo.

El experimento de esta página se ejecuta con JavaScript directamente en el navegador. El código Python del repositorio tiene su propia simulación reproducible mediante una semilla fija.
